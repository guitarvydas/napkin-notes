I do wish, though, that the word "macro" were qualified better. I see there being at least several kinds/degrees of macros:
1. keyboard / action recorder
2. C-style `#define` parameterized & glorified search and replace
3. Lisp-style macros that are actually a kind of code that writes code. This, also, includes languages that provide `eval()` and even shell scripts that can produce and run other shell scripts (and, of course, T2T). [IMO: banning `eval()` from program development languages was the wrong move, maybe it should only be banned from released production code] (`eval()` could be called `compile()`)
