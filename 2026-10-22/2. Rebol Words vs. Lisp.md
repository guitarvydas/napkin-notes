I've been trying to unwind the implementation and meaning of "words" in Rebol.

As far as I can tell a lot of work / information is required to dynamically parse the arity of functions. In Lisp, this is handled by the parenthesis syntax. For example in Rebol, a function with 2 args is 
```
f 1 2
```
whereas in Lisp, this is
```
(f 1 2)
```

In Rebol, blocks are just data structures. In lisp, lists are just data structures, but Eval() assigns a meaning to the first item in a list, i.e. the first item must be a function and the rest of the items are arguments to the function. In Rebol, `do`, which is something like Eval(), works on a per-word basis and needs to figure out the arity of the function. In Lisp, we need syntax that stops Eval() from evaluating a list data structure - that syntax is the "special form" QUOTE (often abbreviated with a shorthand - the single quote mark)

A Lisp expression like
```
(f (g 1) 2)
```
must turn into Rebol like
```
f do [g 1] 2
```

I see that this changes the coding details of expressions, but, I think that there is essentially no difference in capabilities.

I haven't figured out binding in Rebol yet.
