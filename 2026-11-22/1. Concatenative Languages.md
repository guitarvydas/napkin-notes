aside: I think that electronic schematics most accurately model asynchronous reality, but need a facelift (like recursive definitions of ICs as readable schematics themselves).

observation: the "power" of Forth goes deeper than just the stack, the functional paradigm causes deep, hidden coupling (of control flow) when mapped onto hardware which requires the use of (complicated, preemptive) operating systems to decouple (by converting functions into state machines); Forth doesn't cause this issue and makes it possible to break free from using an operating system (I suspect that other concatenative languages lead to this, also, but I've only explored schematic-y ideas (like PBP))
