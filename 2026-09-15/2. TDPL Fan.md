I'm a long time fan of TDPLs and am a hard-core fan of Ohm and OhmJS. I used OhmJS to  create a little DSL for writing "semantics" code for OhmJS. I use that combo to write diagrammatic DSLs. Ohm easily parses graphML, SVG, XML and JSON and emits code in assembly languages like Python, JS, Common Lisp, /bin/bash, Prolog, etc.
